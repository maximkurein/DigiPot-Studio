# Changelog

Все заметные изменения DigiPot Studio. Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии: [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Исправлено
- **Документация отражает два интерфейса.** README, CLAUDE.md, AGENTS.md, `docs/ARCHITECTURE_ru.md`, `docs/INDEX_ru.md`, `docs/FIRST_RUN_ru.md`, BUILD.md и шаблон баг-репорта описывали только React + Tauri; теперь в них есть нативный интерфейс egui. Схема архитектуры перерисована: реальные 8 экранов вместо общих заготовок, три способа запуска (Tauri, веб, egui), SPI вместо «SPI / I²C». Из `docs/release_guide_ru.md` убран чек-лист ручной проверки от другого проекта (планировщик 2.45 ГГц, петля, шум) — теперь экраны DigiPot. `make check` запускает и тесты `digipot-egui`.
- **egui: иконка в Dock.** Без своей иконки eframe при запуске ставил приложению логотип egui (`setApplicationIconImage`), и в Dock была другая картинка, чем в «Программах». Теперь окно получает ту же иконку, что в `icon.icns` (`src-tauri/icons/icon.png`, встроена в бинарник).

### Изменено
- **egui: движок в отдельном потоке** (`crates/digipot-egui/src/worker.rs`). Обмен с мостом, ожидание записи EEPROM (до 10 мс), подключение к порту и сканирование USB больше не подвешивают окно. Интерфейс отправляет задания в очередь и раз в кадр забирает новое состояние, записи журнала и ответы; при простое состояние обновляется каждые 350 мс. Повторные `set_field` одного поля, накопившиеся за время обмена (перетаскивание ползунка через медленный мост), сливаются в одно — на кристалл уходит только последнее значение. В верхней панели появился индикатор, если обмен длится дольше 150 мс.
- `build_macos.py` дописывает `checksum.txt` вместо перезаписи: строки других сборок той же версии (Tauri, egui, сервер) сохраняются.

### Добавлено
- **Нативный интерфейс на egui** (`crates/digipot-egui`, `make egui`): все восемь экранов (потенциометр с кликабельной схемой TCON и графиками, обзор с живой блок-схемой, EEPROM с двухшаговым подтверждением записи, карта регистров с сеткой битов, плата, подключение, академия, о программе), журнал шины с фильтрами и произвольными кадрами SPI, тёмная и светлая темы, ⌘/Ctrl + 1…8 и ⌘/Ctrl + J. Работает без WebView и Node, вызывает движок напрямую и читает тот же файл настроек, что и Tauri-приложение. Tauri и веб-режим остаются без изменений.
- **Сборка egui для macOS**: `python3 build_macos.py --egui [--universal]` (`make build-mac-egui`) — `DigiPot Studio egui.app` с иконкой и ad-hoc подписью, `.dmg` с ярлыком «Программы» и `.app.zip` в `release/vX.Y.Z/`. Node не нужен; bundle id `com.digipotstudio.egui`, так что приложение ставится рядом с Tauri-версией.
- Скил **tauri-to-egui** (`.claude/skills/tauri-to-egui/`, копия в `~/Project/AI/skills/`): перевод любого похожего Tauri-проекта на egui — инвентаризация (`scripts/inventory.py`), заготовка крейта (поток движка, `Shared`/`Act`, тема, снимки экранов), сборка `.app`/`.dmg`, грабли и проверка. Промт для ИИ с порядком работы — `PROMPT_TAURI_TO_EGUI.md`.
- `EGUI.md` — описание нативного интерфейса с примерами кода: immediate mode, `Shared`/`Act`, поток движка и слияние заданий, защита EEPROM, графики и схемы, тема, сборка `.app`/`.dmg`, частые ловушки.
- `Engine::state()` — типизированный снимок состояния (`api::State`); RPC `get_state` теперь сериализует его, формат JSON прежний. Также `Engine::log_since`, `log_head`, `curve`.

## [0.1.1] - 2026-11-08

### Добавлено
- **Экран «О программе»** (⌘/Ctrl + 8, кнопка в правом верхнем углу и подпись версии в боковой панели): название, версия и дата выпуска, разработчик **Kurein M N**, лицензия, сведения о кристалле и текущем режиме запуска, условия использования с правилами безопасности.
- **Ссылки на репозитории** в приложении и документации: GitHub <https://github.com/maximkurein/DigiPot-Studio> и зеркало Forgejo <http://100.64.0.12:3000/mxm/DigiPot-Studio>; кнопка открывает ссылку в браузере (команда Tauri `open_url`, только http/https), соседняя — копирует готовую команду `git clone`.
- `digipot-core::about` — сведения о программе (имя, версия, дата, разработчик, лицензия, ссылки) в RPC `get_meta` (`meta.app`); файл синхронизируется из `config/version.json` скриптом `tools/update_version.py` и защищён тестом на совпадение с `CARGO_PKG_VERSION`.

### Изменено
- **Новая иконка приложения**: резистивная цепочка A→B с движком W вместо прежней абстрактной микросхемы; перегенерированы `icon.icns`, `icon.ico` и PNG.
- Разработчик и ссылки на проект добавлены в `config/version.json`, `Cargo.toml`, `package.json` и метаданные установщиков (`bundle.publisher`, `bundle.copyright`, `bundle.homepage`).

## [0.1.0] - 2026-11-07

Первая версия: лаборатория MCP4161 и платы DIGI POT click (MIKROE-923) для macOS, Windows и веба.

### Добавлено
- **Модель MCP4161 на Rust (`digipot-core`).** Память 16 × 9 бит по даташиту DS22059B; команды SPI (запись/чтение 16 бит, инкремент/декремент 1 байт, непрерывные команды, CMDERR); расчёт R_WB, R_WA, V_W с нагрузкой, шагов, тока, полосы и температурного дрейфа; проверка пределов (VDD, напряжения на выводах, ток 2.5 мА) с пояснениями на русском.
- **Симулятор кристалла**: загрузка движка из EEPROM при включении, цикл записи EEPROM с флагом EEWA, пределы инкремента/декремента, ошибки команд, конфликт на линии SDI/SDO при полнодуплексном чтении, «мультиметр» с R_AB конкретного экземпляра.
- **Экраны**: «Потенциометр» (ползунок, шаги ±, схема с ключами TCON, кривые R и V), «EEPROM» (запись только с подтверждением, счётчик циклов, цикл питания), блок-схема, карта регистров, плата с рядами mikroBUS, подключение, 8 уроков «Академии», журнал шины.
- **Подключение железа**: USB-мост с 3-проводным чтением (команда `T`) — на DIGI POT click MISO не разведён; сканер USB с подсказками.
- **Сборка и выпуск**: единая версия в `config/version.json`, скрипты сборки macOS/Windows, CI и релизы через GitHub Actions.
