# Безопасность

## Поддерживаемые версии

Исправления выпускаются для последней версии (см. `config/version.json` и [CHANGELOG.md](CHANGELOG.md)).

## Как сообщить об уязвимости

Не открывайте публичный issue для проблем безопасности. Используйте приватное сообщение об уязвимости в GitHub (Security → Report a vulnerability) или напишите владельцу репозитория напрямую.

Укажите:

- версию DigiPot Studio и ОС;
- режим (desktop или `digipot-server`);
- что может сделать атакующий;
- шаги воспроизведения или минимальный пример.

## Что хранит и куда обращается приложение

- **Desktop-режим** не открывает сетевых портов. Состояние (регистры, настройки фильтра, опоры) хранится в JSON в папке настроек приложения: `~/Library/Application Support/com.digipotstudio.desktop/` (macOS), `%APPDATA%\com.digipotstudio.desktop\` (Windows). Паролей и ключей нет.
- **`digipot-server`** по умолчанию слушает только `127.0.0.1:7878`. Аутентификации нет: любой, кто может открыть адрес, может записывать регистры подключённой платы. Запуская с `--host 0.0.0.0`, ограничьте доступ (файрвол, VPN, SSH-туннель). CORS разрешён для удобства разработки.
- Приложение не отправляет телеметрию и не обращается к интернету. Исключение — установщик Windows может скачать WebView2, если его нет в системе.
- Последовательный порт и USB открываются только по явному действию пользователя. Сканер USB читает лишь дескрипторы устройств (VID, PID, строки производителя).

## Безопасность железа

Неверное содержимое регистров, как правило, не повреждает MCP4161, но неправильное подключение может:

- логика моста — **только 3.3 В** (проверьте уровни интерфейса в даташите); 5-вольтовые Arduino без преобразователя уровней не подключайте;
- не превышайте абсолютные максимумы входов и выходов (раздел «Absolute Maximum Ratings» даташита);
- перед подключением внешнего моста изолируйте штатный USB-контроллер платы DIGI POT click (MIKROE-923) от линий шины.
